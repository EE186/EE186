* You will be using the [Sparkfun USB logic analyzer](https://www.sparkfun.com/usb-logic-analyzer-24mhz-8-channel.html). If you are using an Apple Silicon Mac, please install [PulseView 0.4.2]({{ '/assets/labs/PulseView-0.4.2.dmg' | relative_url }}).
